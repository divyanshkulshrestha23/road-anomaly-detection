# Data

Raw data and trained weights are not stored in git.

## Sources

- RDD2022 (road damage, includes Indian roads): check licence before use
- Mapillary traffic sign data: check licence before use
- Public pothole datasets (Kaggle and others): record source and licence for each
- Own Delhi road frames and recorded rides: stored in shared drive, listed in `manifest.csv`

## Manifest

`manifest.csv` (to be created) records each dataset: name, source URL, licence, date downloaded, and who owns it.
